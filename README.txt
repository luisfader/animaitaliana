Итальянское настроение

Contenuto del pacchetto:
- index.html
- css/styles.css
- js/tracks.js
- js/app.js
- assets/images
- assets/audio

Note:
- Tutto funziona offline.
- Mantieni esattamente questa struttura di cartelle.
- La playlist si può trascinare sul desktop dalla sua intestazione.
- La cartella audio è assets/audio.
